Turnierverwaltung öffnen
So geht der Import
  1. Hier „Excel-Datei für die Turnierverwaltung“ speichern (landet im Ordner Downloads).
  2. Turnierverwaltung V1.5 starten (Turnierverwaltung_starten.bat). Für ein neues Turnier links „🆕 Neues Turnier starten“.
  3. Schritt 01: Regelwerk wählen, Turniername und Bahnen eintragen, 💾 Speichern.
  4. Schritt 02: „☰ Weitere Funktionen“ → „📥 Excel importieren“ → Datei wählen → 💾 Speichern.
  5. Schritt 03: Spielplan erstellen.

Der Import ersetzt die Mannschaftsliste des aktiven Turniers. Gleichnamige Mannschaften behalten ihre Zuordnung. „Turnierverwaltung öffnen“ geht, wenn sie läuft (am PC Port 8440).
